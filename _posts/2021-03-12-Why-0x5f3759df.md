The line `i = 0x5f3759df - (i >> 1);` from the Quake III Arena source code is the core of the fast inverse square root. Given the bits of a float `x` in `i`, it produces a first guess at $$\frac{1}{\sqrt{x}}$$ that is within 3.5% of the right answer, using one shift and one subtraction. The constant itself can be derived with a logarithm and a bit of algebra.

Games normalize vectors constantly for lighting, reflections and physics, and normalizing a vector means dividing by its length, $$\frac{1}{\sqrt{x^2 + y^2 + z^2}}$$. In the late 90s square roots and divisions were slow, and doing them thousands of times per frame added up. The function below gets a close enough approximation of $$\frac{1}{\sqrt{x}}$$ using only multiplications, a shift and a subtraction.

Here it is written in modern C. The original casts a `float*` to a `long*`, which is undefined behaviour today, so `memcpy` is used instead:

```c
#include <stdint.h>
#include <string.h>

float fast_inv_sqrt(float x)
{
    uint32_t i;
    float y;

    memcpy(&i, &x, sizeof(i));          // read the float's bits as an integer
    i = 0x5f3759df - (i >> 1);          // the magic line
    memcpy(&y, &i, sizeof(y));          // back to a float

    y = y * (1.5f - 0.5f * x * y * y);  // one Newton step
    return y;
}
```

To understand the line with the constant, we first need to look at how a float is stored.

## Float Bits as a Logarithm

A 32-bit float is made of a sign bit, an 8-bit exponent $$E$$ and a 23-bit mantissa $$M$$. For a positive number the value it represents is:

$$x = \left(1 + \frac{M}{2^{23}}\right) 2^{E - 127}$$

Taking $$\log_2$$ of both sides:

$$\log_2(x) = E - 127 + \log_2\left(1 + \frac{M}{2^{23}}\right)$$

Writing $$m = \frac{M}{2^{23}}$$, which is always between $$0$$ and $$1$$, the curve $$\log_2(1 + m)$$ is close to a straight line on that interval. So we can approximate it with $$m + \sigma$$, where $$\sigma$$ is a small correction term (Figure 1):

Plugging that approximation back in $$\dots$$

$$
\begin{aligned}
\log_2(x) &\approx \frac{M}{2^{23}} + \sigma + E - 127 \\
&= \frac{1}{2^{23}}\left(E \cdot 2^{23} + M\right) + \sigma - 127
\end{aligned}
$$

$$\dots$$ where $$E \cdot 2^{23} + M$$ is the integer you get when you read the float's bits as an integer. Calling that integer $$I_x$$:

$$\boxed{\log_2(x) \approx \frac{I_x}{2^{23}} + \sigma - 127}$$

So the bits of a float, read as an integer, are approximately a scaled and shifted copy of its own logarithm.

## Deriving the Constant

We want $$y = \frac{1}{\sqrt{x}}$$. Taking $$\log_2$$ of that:

$$\log_2(y) = -\frac{1}{2}\log_2(x)$$

Replacing both logarithms with the integer approximation from above:

$$\frac{I_y}{2^{23}} + \sigma - 127 = -\frac{1}{2}\left(\frac{I_x}{2^{23}} + \sigma - 127\right)$$

Solving for $$I_y$$:

$$
\begin{aligned}
\frac{I_y}{2^{23}} &= -\frac{1}{2}\frac{I_x}{2^{23}} + \frac{3}{2}(127 - \sigma) \\
I_y &= \frac{3}{2} \cdot 2^{23} (127 - \sigma) - \frac{I_x}{2}
\end{aligned}
$$

The $$\frac{I_x}{2}$$ term is `i >> 1`, and the first term is a constant. Plugging in $$\sigma \approx 0.0450466$$:

$$\frac{3}{2} \cdot 2^{23} (127 - 0.0450466) = 1597463007 = \boxed{\texttt{0x5f3759df}}$$

The $$\sigma$$ that best fits the straight line by itself is closer to $$0.0430$$, so whoever picked `0x5f3759df` probably tuned it for the result after the Newton step rather than for the line.

As an example, take $$x = 10$$. Its bits read as an integer are `0x41200000`, and shifting right by one gives `0x20900000`. Subtracting that from the constant gives `0x3ea759df`, which read back as a float is $$0.3269$$. The true value of $$\frac{1}{\sqrt{10}}$$ is $$0.3162$$, so the first guess is off by about 3.4%.

## One Newton Step

To refine the guess we use one step of Newton's method. We want the root of:

$$f(y) = \frac{1}{y^2} - x$$

since $$f(y) = 0$$ exactly when $$y = \frac{1}{\sqrt{x}}$$. With $$f'(y) = -\frac{2}{y^3}$$, one Newton step becomes:

$$
\begin{aligned}
y_{n+1} &= y_n - \frac{f(y_n)}{f'(y_n)} \\
&= y_n - \frac{\frac{1}{y_n^2} - x}{-\frac{2}{y_n^3}} \\
&= y_n\left(\frac{3}{2} - \frac{x}{2}y_n^2\right)
\end{aligned}
$$

This is the last line of the function, and it only needs multiplications, with no division or square root. For $$x = 10$$ the guess of $$0.3269$$ becomes $$0.3157$$, which is within 0.17% of the true value.

The error pattern repeats every factor of 4, since the square root halves the exponent. Over all inputs, the worst case error is 3.44% from the magic number alone, 0.175% after one Newton step and 0.0005% after two.

Modern CPUs have a dedicated instruction for the same job, such as `rsqrtss` on x86, which gives an estimate accurate to about 12 bits in hardware and can be followed by the same Newton step when more precision is needed.
